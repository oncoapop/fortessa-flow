# Security and data handling

Flow-cytometry files may contain confidential sample identifiers in filenames or FCS metadata.

- Run the software locally unless your organisation explicitly approves another environment.
- Use coded sample identifiers.
- Do not commit FCS files, FlowJo workspaces, local configuration files or generated reports.
- Review the manifest and output directory before sharing results.
- Report security concerns through a private GitHub security advisory rather than a public issue.
